Use macros (saved replies)

Macros are saved replies that can also do the housekeeping for you: add a tag, change the status, hand the ticket to another team. One click replaces a paragraph of typing and three menu changes.

Last updated July 22, 2026 · 3 min read

What a macro does

A macro has two optional parts: a reply and a set of actions. When you apply a macro, the reply text is inserted into the composer, where you can edit it before sending, and the actions are queued. They run when you send the reply, so if you change your mind and discard the draft, nothing on the ticket changes.

Available actions:

  • Set tag: add or remove one or more tags, such as refund-requested.
  • Set status: Open, Pending, On-hold, or Solved.
  • Set assignee: a specific agent, a team, or "Unassign".
  • Set priority: Urgent, High, Normal, or Low. This also changes which SLA targets apply.
  • Add internal note: a note only your team sees, including @mentions.

A macro with actions but no reply is useful too. For example, an "Escalate to billing" macro that tags the ticket, sets priority to High, and assigns the Billing team.

Placeholders

Placeholders are replaced with real values when the macro is applied. Type them in double curly braces:

PlaceholderInserts
{{customer.first_name}}The customer's first name
{{customer.email}}The customer's email address
{{ticket.id}}The ticket number, for example 48213
{{agent.first_name}}The first name of the agent sending the reply
{{order.number}}Number of the customer's most recent Shopify order
{{order.status}}Status of that order, such as "Fulfilled" or "Awaiting shipment"
{{order.tracking_url}}The carrier tracking link for that order

The order.* placeholders come from the Shopify integration, which is available on Growth and above. They use the same data as the order sidebar, which shows the customer's last 5 orders. If the customer has no matching order, the placeholder is left empty and the composer highlights it so you can fill it in by hand.

To avoid an awkward blank, add a fallback: {{customer.first_name | default: "there"}} produces "Hi there" when the first name is unknown.

Example: "Hi {{customer.first_name}}, your order {{order.number}} is currently {{order.status}}. You can follow it here: {{order.tracking_url}}. Your reference for this conversation is #{{ticket.id}}." with actions Set tag: order-status and Set status: Solved.

Personal and shared macros

Personal macros belong to the agent who creates them and are visible only to that agent. Any agent can create them, which makes them good for drafts and individual phrasing.

Shared macros are visible to the whole workspace or to the teams you choose. Admins can create and edit them, as can agents with the Manage shared macros permission. Use shared macros for anything with policy implications, such as refunds or account changes, so everyone gives the same answer. An agent can copy a shared macro into a personal one to adapt it without changing the original.

Create a macro

  1. Go to Settings → Workflows → Macros and click New macro. You can also click Save as macro under any reply you are writing.
  2. Give it a clear name, such as "Shipping: where is my order", and choose Personal or Shared. For shared macros, pick the teams that can use it.
  3. Write the reply and insert placeholders from the Insert placeholder menu.
  4. Add actions: tags, status, assignee, priority, or an internal note.
  5. Click Save. The macro is available immediately in the composer.

Apply a macro

In any ticket, click Macros in the composer toolbar or press Ctrl + Shift + M (Cmd + Shift + M on Mac) and start typing the macro name. Pending actions are listed above the Send button, and you can remove any of them before sending. Macros work the same in the iOS and Android agent apps.

Note: Light (collaborator) seats cannot reply to customers, so they can only apply macros that have no reply text, such as a macro that adds an internal note and a tag.

Macro usage reports

Under Reporting → Macros, you can see how each macro is used across the workspace:

  • Number of times applied, per day, week, or month.
  • Which agents and teams use it most.
  • Average CSAT on tickets where the macro was used, so you can spot replies that frustrate customers.
  • Last used date. Macros not used in 90 days are flagged as candidates for cleanup.

Personal macros appear in the report only for their owner and for admins. Review the report every quarter: macros with high usage and low CSAT are usually the best ones to rewrite, or to turn into a Knowledge Base article that Relay AI can use too.
