Install the chat widget

Paste one snippet into your site and customers can chat with your team. The widget is about 38 KB gzipped and loads asynchronously, so it won't slow your pages down.

Last updated September 9, 2026 · 4 min read

Live Chat is included on every Relaydesk plan. You'll need to be an Owner or Admin to copy the snippet and change widget settings, and you'll need access to edit your website's HTML or theme.

Copy the snippet

Go to Settings → Channels → Live Chat → Install. Your snippet already contains your workspace handle. It looks like this:

<script>
  window.RelaydeskSettings = { workspace: "northwind" };
</script>
<script async src="https://widget.relaydesk.example/v1/loader.js"></script>

Paste it just before the closing </body> tag on every page where you want the widget. Because the script uses async, the browser keeps rendering your page while the widget downloads. The whole widget is about 38 KB gzipped.

Tip: Install the snippet on your site but leave the widget switched to Hidden under Appearance until your team is ready. You can preview it by adding ?relaydesk_preview=1 to any page URL.

Platform notes

WordPress

Use a header and footer code plugin, or your theme's built-in custom code setting, and paste the snippet into the footer section. Avoid editing your theme's footer.php directly, because theme updates overwrite it. If you use a caching or optimization plugin, exclude widget.relaydesk.example from JavaScript combining and delay settings.

Shopify

In your Shopify admin go to Online Store → Themes, click ⋯ → Edit code, open theme.liquid and paste the snippet just before </body>. If you're on Growth or Scale, install the Relaydesk app from the Shopify App Store as well: it adds the order sidebar to tickets and lets agents refund, cancel or edit addresses without leaving Relaydesk. See the Shopify integration.

Webflow

Open Site settings → Custom code and paste the snippet into Footer code, then publish your site. Custom code requires a paid Webflow site plan. To show the widget only on some pages, paste it into each page's own custom code settings instead.

Pre-chat form

A pre-chat form asks visitors a few questions before the chat starts, so agents have context and the chat can be routed to the right team. Configure it under Live Chat → Pre-chat form.

  • Choose which fields to show: name, email and any ticket custom fields, such as order number or topic.
  • Mark fields required or optional. Asking for email is recommended, so you can follow up if the visitor leaves.
  • Use a dropdown field together with assignment rules to route chats to a team, for example Billing or Technical.

Skip the form for visitors you've already identified with identity verification; Relaydesk knows who they are.

Offline mode

When nobody on the team is available, or outside the business hours schedule attached to the widget, the widget switches to offline mode. Visitors leave their email address and message, and the chat becomes an email ticket in the Shared Inbox. The customer gets your reply by email.

If Relay AI Autopilot is turned on for chat, it can answer from your Knowledge Base while you're offline and create a ticket only when it needs to hand off to a human. See Set up Relay AI.

Languages and appearance

The widget is available in 32 languages. It uses the visitor's browser language when it's supported and falls back to your workspace language otherwise. You can also force a language in the snippet, for example language: "pt".

Under Appearance, set the accent color, launcher position, greeting and agent avatars. Turn on Email transcript to send customers a copy of the conversation automatically when the chat ends. Visitors and agents can share files up to 25 MB each.

Identity verification

If your website has signed-in customers, pass their details to the widget so agents see who they're talking to and the customer's chat history follows them across devices. Turn on identity verification so nobody can impersonate another customer by editing the snippet in their browser.

  1. Go to Live Chat → Security and copy your identity verification secret. Keep it on your server only; never put it in front-end code.
  2. On your server, compute an HMAC-SHA256 of the signed-in user's ID using the secret, and output it as a hex string.
  3. Add the user details and the hash to the snippet settings:
<script>
  window.RelaydeskSettings = {
    workspace: "northwind",
    user: {
      id: "cus_48213",
      email: "dana@whitfieldstudio.example",
      name: "Dana Whitfield",
      userHash: "HMAC-SHA256 hex digest of the id"
    }
  };
</script>

Once identity verification is turned on, Relaydesk rejects user details that arrive without a valid hash and starts the chat as an anonymous visitor instead. If you rotate the secret, update your server before you save the new one, or signed-in customers will briefly appear as anonymous.

Mobile SDKs

To offer chat inside your own app, use the Relaydesk Live Chat SDKs for iOS and Android. They use the same settings, pre-chat form, languages and identity verification as the website widget, and support push notifications for agent replies. Find the SDK keys under Live Chat → Mobile SDKs. These SDKs are for your customers; your agents use the separate Relaydesk agent apps for iOS and Android.

Troubleshooting

The widget doesn't appear

Check that the widget isn't set to Hidden, that the snippet is on the page (view the page source and search for widget.relaydesk.example), and that a content security policy on your site allows scripts and connections to widget.relaydesk.example.

The widget is always offline

Check the business hours schedule attached to the widget, including its holiday calendar, and make sure at least one agent on the receiving team is set to Available.
