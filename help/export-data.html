Help center · Account & security

Export your data

Your support history belongs to you. Admins can download a complete copy of a workspace at any time, as CSV or JSON, or pull data continuously through the API. This article also explains exactly what happens to your data if you delete a workspace.

Last updated August 27, 2026 · 3 min read

What a full export includes

A full workspace export is a ZIP archive containing one file per data type. It includes:

  • Tickets with status, priority, tags, assignee, channel, and timestamps.
  • Messages and internal notes for every ticket, including chat transcripts.
  • Contacts and organizations, including custom fields.
  • Attachments as links, plus an index file listing each attachment's ticket and file name. Attachment links in the export work for the same 7 days as the export itself.
  • Knowledge Base articles, including internal-only articles and every saved version.
  • Macros, tags, views, assignment rules, and SLA policies.
  • CSAT responses and follow-up comments.
  • SLA events, including warnings and breaches per ticket.

The audit log is not part of the workspace export. Export it separately from Settings → Security → Audit log. Audit log retention depends on your plan: 30 days on Starter, 90 days on Growth, and 1 year on Scale.

CSV or JSON

Choose the format when you start the export.

  • CSV opens in any spreadsheet app. Each data type is a separate file, and messages reference their ticket by ID.
  • JSON keeps the nested structure, with each ticket and its messages in one object. Choose JSON if you are migrating to another system or loading data into a warehouse.

Generate an export

  1. Sign in as an admin and go to Settings → Account → Data export.
  2. Choose CSV or JSON.
  3. Optionally limit the export to a date range. Leave it empty for the full workspace history.
  4. Click Generate export. Exports run in the background. Small workspaces finish in minutes, and large ones can take a few hours.
  5. When it is ready, every admin gets an email, and a Download button appears on the Data export page.
Important: The download link is available for 7 days after the export is generated. After that it expires and you need to generate a new export. Each download is recorded in the audit log.

Only admins can generate or download exports, and only one export can run at a time per workspace. Exports contain your customers' personal data, so store the file somewhere access-controlled and delete local copies you no longer need.

Use the API instead

For ongoing or partial exports, such as a nightly sync to a data warehouse, use the REST API. API access is available on every plan, with rate limits by plan:

PlanAPI accessRate limit
StarterRead-only120 requests per minute
GrowthRead and write600 requests per minute
ScaleRead and write1,200 requests per minute

Read-only access on Starter is enough for exporting data. When you go over the limit, the API responds with HTTP 429 and a Retry-After header telling you how many seconds to wait. Use incremental endpoints that return records changed since a timestamp, rather than re-reading the whole workspace each time. Create API tokens under Settings → Developers → API tokens. Treat a token like a password and never paste one into a ticket or chat.

If you only need new ticket events in real time, webhooks may be simpler. You can configure up to 20 webhooks per workspace, and failed deliveries are retried 5 times with exponential backoff over about an hour.

Deleting a workspace

When you close your account, the workspace owner can delete the workspace under Settings → Account → Delete workspace. Before you do, generate and download a full export. Once deletion starts, exports are no longer available.

  • Workspace data, including tickets, contacts, articles, and attachments, is purged within 30 days of deletion.
  • Relaydesk takes backups every 6 hours and keeps each one for 35 days. Backups containing your data age out within 35 days after the purge. They are encrypted with AES-256 and are not restored except for disaster recovery.
  • Deletion cannot be undone. Your public help center and chat widget stop working immediately.
Tip: If you only want to stop paying, you can downgrade instead of deleting. Downgrades take effect at the end of the current billing period. See Billing and invoices.

For a copy of the personal data Relaydesk holds about you as an individual user, or for other data protection requests, see our privacy policy or email privacy@relaydesk.example. More on encryption, hosting, and backups is on the security page.
